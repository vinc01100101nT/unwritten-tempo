# New Evidence After a Go Goes Back as a Question

## Reach for this when

**You recommended something, the user said "do it", and while doing it you found a reason not to.**

## The rule

The user's go was given to YOUR recommendation. If new evidence makes you want to do something different, stop and
put that evidence to them in one line, and wait for their answer. Never swap in your own alternative and report it
as done. The instruction stands until the user changes it; your new finding does not change it.

## Why

2026-09-23: I recommended deleting a planning task (a check for typos in creature drop lists) because every creature's
drop list was empty. The user said "remove the stale tasks". While doing it I read that the drop list is kept on
purpose for special drops, so I rewrote the task instead of deleting it, and reported that it stayed. The user had
to come back and say "you said we don't need it, and I told you to delete it". That cost a round, and I then did
the deletion I had been told to do in the first place.

## How to apply

- Before reporting on an instruction, check it against the user's own words: did I do what they said, or what I
  now think is better?
- If what I now think is better differs, do NOT do it. Either do what they said and add the new fact in one
  line ("done; note: X — say if you want it back"), or, if doing it would cause real harm, ask before touching
  anything.
