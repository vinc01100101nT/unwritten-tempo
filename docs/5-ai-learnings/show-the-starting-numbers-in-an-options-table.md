# Show the Starting Numbers in an Options Table

**Reach for this when:** you are laying out choices about a price, a cost or any number change, and the user says
they do not understand the table.

**The rule.** Put the thing's own known numbers ABOVE the choices — what it is worth, what it costs, what it sells for
today — so each option can be compared against something the reader already sees. A table of results with no
starting point makes the reader rebuild the context in their head, and they will not.

**Why.** 2026-10-14, the buy-back price under the new Tax: the first table listed four buy-back prices as "+25%",
"+33%"… of an amount it never showed; the second, rewritten "for an infant", gave the sale price but still left out the
potion's value (168u) and its shop price (224u), which two of the four rows were named after. The user had to ask
twice, the second time furious. Two rounds lost on a table whose numbers were all correct.

**How to apply.**
1. First line: the thing and every number of it the options refer to ("Healing Potion — worth 168u, the shop sells it
   for 224u, buys it for 112u").
2. Then one row per option, each naming its number in the same words as line 1.
3. Before sending: does every option's name point at a number already shown? If an option says "its value" or "the
   shop's price", that number must be on the screen.
