Unwritten

Download the launcher and run it. It downloads the game the first time, keeps it up to date after that, and starts it when you press Start.

Windows

Download for Windows

Unzip it, open the unwritten folder, and run unwritten-launcher.exe. The game is downloaded into that same folder.

Mac

Not sure which chip your Mac has? Open the Apple menu (top left) ▸ About This Mac. "Chip: Apple M…" means Apple chip; "Processor: Intel…" means Intel.

Download for Mac (Apple chip) Download for Mac (Intel)
  1. Open your Downloads folder and double-click the zip. It unzips into unwritten.
  2. Double-click unwritten. The first time, the Mac says it could not verify that "unwritten" is free of malware, because the game is not yet registered with Apple. Press Done — not Move to Trash.
  3. Open System Settings ▸ Privacy & Security.
  4. Scroll down to the Security section. A line says "unwritten" was blocked, with an Open Anyway button. Press it, and enter your Mac password.
  5. Double-click unwritten again and press Open. From then on it opens normally. It downloads the game the first time, then press Start.

If no Open Anyway button appears: open Terminal (Applications ▸ Utilities ▸ Terminal), paste this line, press Return, then double-click unwritten again:

xattr -dr com.apple.quarantine ~/Downloads/unwritten.app
