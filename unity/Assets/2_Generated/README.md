# Generated — tool output, regenerable

Everything here is written by a tool — a `Tools ▸ unwritten ▸ …` menu (ground meshes/materials,
baked 8-dir character sprites, decimated meshes), `tools/sprite-sheet-to-weapon.py` (`Weapons/`, a 3D weapon
model and its texture per sprite sheet) or `tools/image-to-3d.py` (`WeaponModels/`, a weapon model Trellis.2 made
from one picture). **Never hand-edit** —
re-run the tool instead. Deleting a file here loses nothing that a re-bake can't rebuild
(scene links break until you re-bake, so re-bake right after).
