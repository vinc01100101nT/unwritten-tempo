# Generated — tool output, regenerable

Everything here is written by a `Tools ▸ unwritten ▸ …` tool (ground meshes/materials,
baked 8-dir character sprites, minimaps, decimated meshes). **Never hand-edit** —
re-run the tool instead. Deleting a file here loses nothing that a re-bake can't rebuild
(scene links break until you re-bake, so re-bake right after).
