# WHERE THE SERVERS ARE, for a copy of the game that has no terminal to be told by.
#
# NOTHING IS TYPED HERE. Every address lives in settings.env at the top of the project, the one file every
# program reads. tools/build-game.sh copies the addresses into each BUILD's copy of this file after building:
#
#   ACCOUNTS_URL=...       from PUBLIC_ACCOUNTS_URL (or ACCOUNTS_URL while that is empty)
#   CHAR_SERVER_URL=...    from PUBLIC_CHAR_SERVER_URL (or CHAR_SERVER_URL while that is empty)
#
# and tools/publish-update.py adds GAME_VERSION=... to a build it publishes. Only those names, never a secret.
#
# The EDITOR, opened from the Dock rather than a terminal, reads the two addresses straight from settings.env.
# A value set in a terminal still wins over both.
