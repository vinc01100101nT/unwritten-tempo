Recurring spec for the "unwritten" solo-mmorpg YouTube devlogs, so each upload is faster.

**Start date:** game dev began **2026-06-12** (day 1). Compute "day N" as (upload date − 2026-06-12) + 1. Reference: 2026-07-05 = day 24.

**Series marker:** files/series use `game-dev-NN` (game-dev-08 = the 2026-07-05 one). Marker is NOT searchable alone — always pair with a searchable public title.

**Public title format:** `making an mmorpg from scratch — day N | game-dev-NN` (searchable hook + day count + series marker at end).

**Logo / title card (thumbnail + channel cover):** word **unwritten**, all lowercase (matches user's lowercase-only typing = personal brand), font **Playfair Display**, letter-spaced, white fill + black stroke, Normal blend (NOT Difference — it goes rainbow over busy bg). Centered over a diagonal split thumbnail (warm/high-camera scene vs cold/low-camera rainy-reflection scene, diagonal seam via polygon-lasso delete + white stroke).

**Export (CapCut):** mp4, H.264, 1080p (2K only if source is sharp), AAC audio, match source fps. YouTube thumbnail is uploaded separately (CapCut cover ≠ real thumbnail).

**Hashtags (first 3 show above title):** `#devlog #indiegame #gamedev` then `#solodev #madewithunity #unity3d #indiedev #mmorpg #rpg #gamedevelopment #indiegamedev #unwritten #gamedevlog #unity #indiegames`. Do NOT tag other games' names (#ragnarok/#ro) — frame RO as *inspiration* in the description text instead.

**Voice:** captions on-screen (no voiceover); all lowercase; no icons. Video structured in phases.

See also [[unwritten-foundation-first]].

**Written update-post format** (the only surviving record of this — the separate note it pointed at was never written): all lowercase, no icons; sections in the order *new assets / weather / next*.
