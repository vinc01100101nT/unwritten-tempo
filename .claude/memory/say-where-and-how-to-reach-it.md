When I build a new map, area or feature for the user to try, the report says WHERE it is (the map id) and HOW to get
there (the exact chat command, e.g. `/tp seamless_test center`, or the door/route), plus anything needed first (a rebuild,
a restart). Never assume they know which map I made.

**Why:** 2026-10-26, I reported the seamless test world as built without naming the map or the teleport command; the
user: "why you did not tell me which map is it, where to tp, do you assume that i already know".

**How to apply:** before sending any build report, check it answers "where do I go and what do I type to get there".
