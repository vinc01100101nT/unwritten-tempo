Charges spend on FIRE, never refunded (`StateGate`).
- [Buffs ADD, never compound](../additive-not-compounding-buffs.md) — same-category multipliers sum their bonuses (two +30% = ×1.60); players mentally add, so tooltip math must match engine math. Slow is the exception (harshest wins).
- [magnitude is ALWAYS a bonus fraction](../magnitude-always-bonus-fraction.md) — 0.3 = +30%; it used to mean absolute-multiplier when non-stacking and per-stack-bonus when stacking, so Momentum's 1.03 ran as +103%/stack and the composer slider (min 1.0) couldn't author the right value.
- [Damage buff must SUM every pile](../damage-buff-summed-not-first-pile.md) — rolls read only the FIRST DamageBuff pile while its aspd/cast siblings summed; Momentum+Lock Blades lost 27.5% damage. Now live-computed (not cached) so the ramp can't go stale.
- [Attacker owns the accuracy roll](../attacker-owns-the-accuracy-roll.md) — order is crit → accuracy → damage; Combat.Lands is RANDOM so it rolls once on the attacker and travels in DamageInfo.missed. Only 2 accuracy rolls exist; skills always land.
- [Mobs deal damage by the player's rules](../unified-unit-stats-implemented.md) — `UnitOffense.Dealt`/`AttackInterval` are the outgoing twin of UnitMitigation; mob damage/attack-speed buffs used to be ignored entirely (raw `attack` + raw `touchInterval`).
- [Buff buffs, debuff debuffs — separate effects](../buff-and-debuff-are-separate-effects.md) — HARD user rule: never author a debuff as a negative magnitude on a buff knob; the effect NAME carries direction. Existing violation: Haste's signed -0.9..2 slider (SkillComposerWindow.cs:1085).
- [Stack piles: two states + count-vs-carried readings](../stack-piles-two-states-and-readings.md) — a mechanic needs TWO states when one pile must vanish on use while another outlives it (Brace's charges vs its debt); consuming splits into MEASURED-by (Count/CarriedTotal) and what it BUYS (payoff) — two dropdowns, never one.
- [Mitigation must REACH the caller](../mitigation-must-reach-the-caller.md) — ApplyHitToHP took damage by value, so absorbed/braced hits still flashed, reflected, charged the ult and paid the attacker its number + XP. Now returns what landed.
- [NO classes — weapons+skills define gameplay](../no-classes-weapons-define-gameplay.md) — class system doc is stale/deleted; identity = equipped weapon's skill kit + ring build; rosters are per-weapon.
- [Weapons are 3D, no 2D weapons](../weapons-are-3d-no-2d.md) — a weapon Item is real only with a 3D equipModel; kept: Iron Sword + Bow Epic; Katana/Sai/Dawnbreaker retired.
- [Ring stats: always LOOP order](../ring-stats-canonical-order.md) — list the 10 ring stats as Def→HP→Atk→Accuracy→CastSpeed→MAtk→MP→Evasion→Critical→AttackSpeed (from SkillRing.Ring), never enum order.
- [Name knobs concretely, one job, no dead knobs](../name-knobs-concretely-one-job.md) — label every field/effect by the exact thing it changes (never "potency"/"magnitude"); one responsibility each; hide fields that mean nothing in a case. - [The WHOLE skill runs on the server](../whole-skill-runs-on-the-server.md) — only Damage ever crossed before (12 of 57 effects); now one `SkillCastRequest` and the same `SkillRunner` resolves everything server-side, with effect lengths baked into the effect table so beats fire with no particles. - [Lifetime XP is SAVED, not derived](../lifetime-xp-is-saved-not-derived.md) — `lifetimeXp` in save v10+, counted in `AddXP`; the level curve lives once in `UnitStatMath`; a GM level-set raises a floor only; old rows back-filled by migration 005.
- [Rarity lifts a skill's OUTPUT — and does nothing else](../rarity-lifts-skill-output.md) — 0/3/9/18/30 POINTS added to the ring's term (say points, not %); NOT kit size, ultimate, refine or card slots. - [Stat jumps + MELEE/RANGED attack + always-physical creatures](../stat-jumps-and-melee-ranged-attack.md) — every primary jumps every 10 (⌊s/10⌋²+3⌊s/10⌋, gear counted); held weapon picks melee (STR) vs ranged (DEX) attack for normal attacks AND physical skills; creatures crit by the player's rule and never attack with magic; evasion no longer touches magic.
