**Dash skill (added 2026-07-21):** Blink's visible sibling. Blink = `SkillEffectKind.Teleport` → `Player3DController.Teleport(point)` (instant). Dash = `SkillEffectKind.Dash` → `Player3DController.BeginDashToPoint(point)` — the player VISIBLY rushes to the same aimed, range-clamped cast point via `controller.Move` (so walls block it, unlike blink). Author it exactly like Blink: `SkillTargets.Player` + Ground aim; the skill's RANGE is the max distance. Speed = player field `skillDashSpeedMult` (default 8) × `CurrentRunSpeed`; safety cap `skillDashMaxTime` (1s). Reuses the existing charge gap-closer state/step (`dashing`/`StepDash`) with a new fixed-point path (`dashToPoint`/`dashPoint`); `BeginDash(Transform,…)` was a DEAD/unused API before this. Plays the Roll stance (PlayerStanceBrain `Dashing`→Roll). Files: `SkillEffect.cs` (enum append), `Player3DController.cs` (fields + `BeginDashToPoint` + `StepDash` point path), `SkillEffectApplier.cs` (Dash case, self-only), `SkillTooltip.cs`, `SkillComposerWindow.cs`.

**⚠️ Non-obvious gotcha — aftercast root would cancel any multi-frame skill movement.** `SkillRunner.PlayCycles` calls `StatusController.LockActions(releaseDur)` (RO aftercast) **BEFORE** it ticks the effect (`VfxDirector.Play`→`onTick`→effects). So when `BeginDashToPoint` runs, the player is ALREADY `ActionLocked`, and the movement Update's `if (status.ActionLocked){ dashing=false; … }` block would kill the dash on the next frame. Blink is immune (instant reposition already done). Fix: that block now lets a dash-to-point CONTINUE through the aftercast — `if (dashing && dashToPoint && !status.CannotAct){ StepDash(); return; }`. Key distinction (StatusController): **`CannotAct`** = hard-CC ONLY (Stun/Freeze) — cancels the dash; **`ActionLocked`** = `CannotAct || recoverUntil` (includes the skill's OWN cast/aftercast self-root) — must NOT cancel the caster's own dash. Any future "move the player during a skill" (charge, leap, knockback-self) must ride this same `!CannotAct` exemption or it'll be self-cancelled by its own aftercast. See [[stance-system]] (Dashing→Roll), skill effect routing in `SkillEffectApplier.ApplyEffectsToPlayer` (self effects land on the caster at the aimed `point`).
