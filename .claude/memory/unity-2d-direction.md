The actual game is being built in **Unity (2D), Personal tier** — single-player vertical slice first, networking/MMO deferred.

**Design direction (confirmed 2026-06-13):** it's an **open-world, persistent MMORPG**, NOT a per-run roguelike. The only thing borrowed from roguelikes (for now) is the **skill-draft choice on each *character* level-up** (persistent character progression, no permadeath; "per level" = per character level, not per stage). Seasonal reset is a maybe-later. The PRD still says "runs" — reinterpret that as per-character-levelup. Considering adopting the ChatGPT story: World Heart shattered → Echo Rifts → Seekers → spirit companions → hybrid classes → a 5-faction belief-driven war. Skill-system structure is still undecided; foundation work doesn't depend on it.

**This git repo (Vite + React at the root) is NOT the product** — it's the UX prototype for the skill-draft system + the planning home (Tempo docs/issues). Don't treat the React app as the deliverable.
