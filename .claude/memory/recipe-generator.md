**Built 2026-06-22.** unwritten now has ONE world generator: a content-driven recipe. There is no "town generator" vs "field generator" — a map is whatever ground + prop groups + mobs you put in the recipe, so a **town** (Houses in StreetRows + a Tavern in Center), a **field** (Scatter Trees + mobs), and a **dungeon** (your dungeon prefabs) all come from the same generator, differing only in content.

**Files:**
- `unity/Assets/Scripts/MapRecipe.cs` — runtime `ScriptableObject` (`Assets ▸ Create ▸ unwritten ▸ Map Recipe`). Holds: identity (`mapName`, `seed`, `randomizeSeed`); ground (`sizeX/sizeZ`, `dirtAmount` — **always the blended grass→dirt style; the GroundStyle choice was removed 2026-06-22, all maps blend**); **paths** (`pathTile` enum Road/Soil/Stones/Rock, `pathCount`, `pathWidth`, `pathWander` — see the PATH SYSTEM note below; this **replaced the old single `pathHalfWidth` float** 2026-06-22); `propGroups`; `mobGroups`; `forestAmbience`.
  - `RecipePropGroup`: exact `prefabs` **and/or** a `PropCategory` (auto-fills the known Pxltgr names when prefabs empty); `PlacementRule` = **Scatter / EdgeRing / StreetRows / Roadside / Center / Grid / PerimeterWall**; `AmountMode` Density|Count; `solid` (keep colliders) vs decor (stripped); scale+jitter; `minSpacing`; `clearFromCenter`; `avoidPath`; `rowOffset` (StreetRows).
    - **`Grid`** (added 2026-06-23, for walled towns): buildings on a rectangular block grid (`minSpacing`=cell pitch). Reuses `TryPlaceAt` so SOLID buildings auto-skip the routed path band → the roads carve the streets and the leftover cells form blocks. `clearFromCenter` keeps a central plaza open; set `randomYaw=false` for aligned blocks.
    - **`PerimeterWall`** (added 2026-06-23): assembles the Pxltgr modular wall kit (`Wall_part1/2` straights, `Wall_tower1/2` corners, `Wall_entrance`/`Wall_gateL/R` gate) around the inset rectangle via `BuildPerimeterWall`. Straight piece is **bounds-measured** at bake for its run length + run axis, so it tiles seamlessly at any scale; gate gap centred on the SOUTH (min-Z) edge; pieces register as blockers so a later Grid group won't overlap. ⚠️ **Orientation is guessed** (kit's authored facing isn't knowable from code): far edges flipped 180° to face inward — flip the `WallFacingSign` const if walls face outward in Play. New helper `SeatPiece` = explicit-yaw seat (vs the random-yaw scatter path).
  - `RecipeMobGroup`: `archetypeName` ("" = weighted mix, or a MobRoster name, or "Boss"); density/count; `minSpacing`; `clearFromSpawn`.
- `unity/Assets/Scripts/Editor/RecipeGenerator.cs` — the baker + placement engine. `Generate(MapRecipe)` returns `(bool ok, string path, int props, int mobs)`, bakes `Assets/Scenes/<mapName>.unity` (overwrites), registers Build Settings, puts a `Start` spawn at centre, leaves the map open. ⚠️ **`MapRecipeEditor.cs` was RE-ADDED 2026-06-23** (it had been deleted earlier the same day in favour of World-Creator-only baking). Reason: the user wants a **single map baked directly from its recipe without World Creator** (World Creator = multi-map only, per the user). It's a `[CustomEditor(typeof(MapRecipe))]` with a **⚒ Generate Map** button (select the `.asset` → button in Inspector → calls `RecipeGenerator.Generate`). So `Generate()` now has TWO callers again: this inspector (single map) + World Creator's Build World (multi-map world). Authored recipes are still created via `Assets ▸ Create ▸ unwritten ▸ Map Recipe` (CreateAssetMenu). The `Apply Foliage Wind to Open Scene` menu is kept.

**Reuses (didn't reinvent):** `PxltgrGroundBlend.LayPlot` (the one ground; tiled `PxltgrGround.LayPlot` was deleted, `PxltgrGround` now just hosts the shared `AddWalkableFloor`), `PropPlacement.PlaceOnGround`/`StripColliders`/`TryWorldBounds` (bounds-driven seating — see [[fantasy-town-pxltgr]]/[[authoring-toolkit-prop-palette]]), `RegionBuilder.MakeSpawn` + the portal/warp helpers, `Build25DSpike.BuildMonster`/`BuildLight`/`MonsterSheet` + `MobRoster`, `WorldBuildUtil`, `DayNightAmbience`. All randomness flows from `seed` (recipe + seed → same map). Honors [[world-ground-standard]] (Y0 / Ground layer) and [[performance-first-prebake]] (bake at generate time).

**⚠️ DELETED in the same change (the "other generators" are gone):** `PxltgrFieldBuilder.cs`, `PxltgrScatter.cs`, `NatureMobs.cs`, `FantasyTownBuilder.cs`. **`RegionBuilder` was trimmed** — removed `BuildTownHub`/`LinkFieldToTown`/`RelinkRegion`/`RefreshWarpFxInScene`/`LinkFieldBack`; **kept** the portal/spawn/warp infra (`MakeSpawn`/`EnsureSpawn`/`MakePortal`/`EnsurePortal`/`AddWarpFx`/`FitTriggerToFx` + `ClassifyDestination` colour convention, see [[portal-color-convention]]), `Spawn Field Boss`, `Fit Portal Triggers`, `Drop Selected to Ground`. So [[pxltgr-field-migration]] and [[fantasy-town-pxltgr]] describe the now-deleted bakers — use this recipe flow instead (the FbxPropExtractor / ×0.3 / bounds-driven facts in those notes still hold).

**Map linking — RETIRED 2026-06-23.** The old manual linker (`MapLinker.LinkMaps` + the `MapLinkWindow` after-generate popup + the `LinkMapsWindow` / `Link Two Maps…` window, all in `MapLinkWindow.cs`) was **DELETED**. Warp wiring is now done declaratively by **World Creator's Build World** ([[world-creator-pipeline]]) — paired portal+spawn on both maps, spawn ids keyed `w{i}_from_<map>`. The `From_<map>` `EnsureSpawn`/`EnsurePortal` helpers still live in `RegionBuilder` but no longer have a caller.

**⭐ PATH SYSTEM (built 2026-06-22, replaced the straight `pathHalfWidth` center-strip):** real winding routed paths, with their own distinct tile, that nothing blocks.
- **Shader** `GroundBlend.shader` now layers THREE textures via vertex color: `.a`=grass↔dirt blend (unchanged), **`.r`=path weight** → `albedo = lerp(lerp(grass,dirt,a), path, r)`. Added `_PathMap`/`_PathTiling` (the RGB was previously unused white).
- **Path STYLE (added 2026-06-23):** recipe enum `PathStyle { Winding, Cardinal }` (field `pathStyle`, default Winding). **Cardinal** = `PathRouting.BuildCardinal(center,sizeX,sizeZ)` → a straight plaza-centred **cross**: exactly two dead-straight routes (E↔W + N↔S) crossing at the true map centre, roads only to the 4 edge midpoints (N/E/S/W), no hub jitter/wander/extra spokes (ignores `pathCount`/`pathWander`); the south spoke lines up with the PerimeterWall south gate. Used by Prontera. `RecipeGenerator.Generate` picks BuildCardinal vs Build off `pathStyle` (when not routing to warp exits).
- **`PathRouting.cs`** (NEW, `Editor/`) — `Build(center,sizeX,sizeZ,count,wander,seed,smoothness=0)` → `count` winding polylines edge→shared centre **hub**→opposite edge (2+ routes ⇒ a **crossroads**); even routes run L↔R, odd run B↔T. Bends = tapered sum-of-sines so endpoints stay anchored & it never self-folds → **angular/faceted corners** (piecewise-linear, no spline). `smoothness` (0–3) runs **Chaikin** corner-cutting passes that round the corners into curves, keeping the edge endpoints anchored (the hub rounds slightly — harmless, wide path still overlaps into a crossroads). Recipe knob `pathSmoothness` defaults **0** (keeps the angular look the user liked). Helpers: `MinDistanceXZ(p, routes)` (point→nearest-segment dist) and `Walk(route, spacing)` (yields `(pos,dir)` along a route).
- **`PxltgrGroundBlend.LayPlot`** signature changed: `roadHalf` float → `(IReadOnlyList<PathRouting.Route> paths, float pathWidth, string pathTexName)`; bakes per-vertex feathered distance-to-nearest-segment into color **`.r`** and textures the path from the `ground_*` prop's Base Map (Road/Soil/Stones/Rock; falls back to dirt).
- **`RecipeGenerator`** routes the network **once** then feeds ground + placement + clearance. **Option 2 chosen (houses follow the road):** `StreetRows` walks the **longest "main" route** and offsets houses ±`rowOffset` perpendicular to the local road dir (curve with the street); `Roadside` does the same along **all** routes at `pathWidth/2+1.5`. No path ⇒ both fall back to the old straight rows at `center.z`. **Unobstructed guarantee:** `TryPlaceAt` rejects any **solid** prop within `pathWidth/2 + PathMargin(0.75)` of any segment (decor avoids only if `avoidPath`). `PathTexName(PathTile)` maps the enum → `ground_road/soil/stones/rock`.
- **Migration:** existing `StarterTown Recipe*.asset` keep an orphaned `pathHalfWidth` YAML key (harmless, Unity drops it) and deserialize the new path fields to C# defaults (Road, count 1, width 3.5, wander 0.5) ⇒ they get one winding road for free; bump `pathCount` to 2 for a crossroads. The starter-recipe menu now seeds count 2 / width 4.5.

**Known follow-ups:** A dungeon FLOOR still needs a new ground texture/builder (dungeon PROPS already work via prop groups). Mob selection is per-group archetype-or-weighted; per-prefab mob weighting not exposed yet. Path routing is piecewise-linear (no spline smoothing) and doesn't yet snap to/around `Center` landmarks — a landmark could sit near a route (clearance keeps props off the path, not the path off props).
