**Tempo doc `q17c22jpppnztax6q9ppndmfds89n0x5`** — "Active Skill Design Charter — Anti-Stale Rules". GUIDE/CHARTER to apply when building the active-skill system. Created 2026-06-30. Linked to the Trio-Ring, Ring of Progression, and Class System docs.

What it locks:
- **Anti-stale rules** (§1–7): flat draft, NO prerequisite gating (kills forced filler); every active needs a non-damage VERB; combo/condition design; dense affix drip between skills; category × element two axes; litmus test ("you press this when ___, afterward the fight is different because ___"). Pre-ship checklist in §7.
- **§8 Modifier system — hook-by-phase architecture**: don't author thousands of skills; author ~25 base skills + a pool of loose modifiers that plug into 6 skill-lifecycle phases (Cast / Targeting-Shape / Impact-Damage / On-Hit / On-Cast-Self / Trigger-Proc). One modifier per phase max. ~30 authored modifiers → effectively unlimited combinations (combinatorial, not enumerated). Variety lives in the BASES, modifiers are the polish layer.
- **§9 Progression — two pick-currencies**: NEW base skill every 10 levels (roster breadth) + modifier picks in between (depth per skill); slot cap per skill forces a broad kit.
- **§10 Balance governors (PvP-safe)**: DR on the effect (CC decays per target) + resist stat + opportunity cost + rarity/copy-caps. Framed on [[conservation-as-balance-driver]].
