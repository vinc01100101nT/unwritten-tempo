When the user says "let's proceed with the X roster" while my open design questions for X are still unanswered, they mean **continue the design conversation**, not "build it with your recommended picks".

**Why:** on 2026-09-23 I read "let's proceed with the armors roster" as a go, declared my picks as decisions and spawned a planner. The user stopped it: "stop the planner agent, we are not done yet. just bring up where we left on armors." A wasted planner run and a round.

**How to apply:** if questions I asked are still open, "proceed" = bring the open questions back up, compactly, and wait. A real go reads like "go with your picks", "go ahead", "proceed with the implementation now". Relates to [[the-five-anti-invention]].
