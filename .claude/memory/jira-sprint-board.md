- **Left Jira on 2026-09-13** (user: "let's leave jira now … use our local action-plan for a while, while we are still finding out a better agile system"). The `atlassian` MCP server is still installed at LOCAL scope (`https://mcp.atlassian.com/v2/mcp`) but unused. The Jira project "unwritten" (key `SCRUM`, cloudId `d34b3d44-85fe-4b47-a767-3cdc217ddd7b`, board id 1) still holds 13 goal epics (SCRUM-5..17) and 38 tasks (SCRUM-18..55) plus the leftover sample SCRUM-4, and one sprint "SCRUM Sprint 0".
- **Why it was left — what the Atlassian MCP could NOT do** (measured by the sprint-manager, 2026-09-13): delete a ticket, a sprint or a dashboard; create a Jira project; change a ticket's type ("The issue type selected is invalid"). Jira refuses sprint names ≥30 chars. Every item — epics included — takes the next number from one counter, which the user found confusing ("SCRUM-14 is a folder?"). Auto-mode's classifier also refused some of its calls as "External System Writes".
- **Tracking now:** `docs/1-planning/action-plan.md` checkboxes + the wiki Roadmap page `wiki/content/roadmap.json` (a `timeline` block: planned on top, one `now`, done below newest-first). The `sprint-manager` agent is the ONLY one that ticks a task or moves a Roadmap entry (project CLAUDE.md RULE TRACKING); it may write only those two files, fenced by `write_scope_gate.py`. Week 1 + Week 2 goals = the "Checking the foundations" entry; MT-34 (bow skills) = "More weapons"; MT-35 + its subtasks (cards) = "Cards". Task IDs (user's format, 2026-09-13): main task `MT-N` (MT-1..MT-37 in plan order), subtask `ST-N-A` indented under its parent (N = parent number, letter = order); never renumbered or reused.
- **Still-true lessons carried over:** a guard waits for the user's go, it never removes access (user: "we only block it with guards waiting our go signal, not access"). Epics/goals say what work is FOR, never a week; a sprint is a time box you can pull more into when finished early. An agent-file edit reaches the agent only in a conversation started after the edit.
