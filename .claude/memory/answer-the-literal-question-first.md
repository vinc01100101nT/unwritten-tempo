Answer the literal question in the first sentence, in the user's own terms: "Yes, it has grass — it's already in the fields."
Nothing about how a vendor's demo was built, instance counts, or what a full solution would need unless asked.

**Why:** 2026-10-26, the user showed a store screenshot of grass and asked if it was achievable. The grass was already
placed in the test world, yet I replied twice with the pack demo's terrain and 665,451 grass instances and a proposal
for a new grass system. The user was furious: the honest answer was "yes, it's already in".

**How to apply:** before sending, ask "did my first sentence answer exactly what they asked, with something they can
go and look at?" If the thing already exists, say so and where, and stop. Related: [[no-number-walls-in-decisions]].
