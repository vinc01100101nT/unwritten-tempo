**Tempo doc `q17122jsbff6fpvswcg3ht7w6989ka3m`** — "Ring of Progression — Tradeable Life's-Work (Design Concept)". DESIGN CONCEPT, not committed code. Started 2026-06-29.

Core: the trio-ring becomes an actual equippable Ring holding the player's PROGRESSION (level/XP + % bonuses + drafted affixes + active skills), tradeable. Character = identity (name/social/class label, flat stats); Ring = power/life's-work (% multipliers, NOT flat stats — flat comes from char/gear/cards). Unequip = "diminished, not erased."

Key locked/leaning ideas:
- **Conservation economy** — rings never minted/crafted/dropped, only SWAPPED; total rings = total players (see [[conservation-as-balance-driver]]).
- **Lineage** — a ring outlives owners, inscribes all past bearers; stats fungible, story is not.
- **Role versatility via presets** — one ring holds multiple build presets (loadouts) so players flex roles without rolling alts; lineage tied to the level-forging, independent of active preset.
- Open holes: barter double-coincidence-of-wants, currency-side sink/burn split, exact flat-vs-% split, anti-RMT.

Sibling design: [[active-skill-design-charter]] (rules for the active skills the ring drafts). Related game systems linked in MEMORY.md (skill-system, class-system, stat-distribution).
