When the user says "list that issue for now" mid-brainstorm, keep it on a running list in the conversation and repeat that list when they ask to batch the issues. Do NOT add it to the action plan or any doc.

**Why:** 2026-10-21, bow skill brainstorm: I put the slow-cap issue into the backlog as a task; the user only meant "keep it on a list this session, we will batch mention them later". It also broke the no-doc-edit-until-final rule.

**How to apply:** keep an "Open issues so far" list in my replies; only write a task when the user says backlog / action plan / add a task.
