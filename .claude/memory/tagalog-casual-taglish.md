When the user asks me to answer in Tagalog ("sagot ka ng tagalog"), reply in **casual Taglish**: everyday
spoken mix, English technical words left in English, contractions and particles ("gets", "kasi", "yung",
"diba") kept. Do NOT write formal or literary Tagalog — no "tuntunin", "disenyo", "patakaran", no
newscaster register, no translating technical terms into deep Tagalog.

**Why:** the deep-Tagalog version reads stiff and unnatural, like a press release; the user asked for
Tagalog to make the exchange easier, and formal register does the opposite.

**How to apply:** write it the way it would be said out loud in a Manila dev conversation. Keep the same
honesty and brevity rules — this changes the register only, not the content. Related: [[skill-tooltip-voice]].
