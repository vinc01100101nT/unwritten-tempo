As of 2026-10-26 the game has no players. In any world or map rework:
- Saved characters are never a constraint: no migration, no moving them; the user deletes them if needed.
- Existing fields and dungeons are disposable: delete, replace or extend freely, no old-to-new mapping, no keeping their ids.
- Only the 16 towns and the 14 special places (landmarks) are kept as they are.

**Why:** the user was angry that a world-layout plan included character migration and carrying old fields over ("dont mind the characters, we have no players yet"; "fields and dungeons can always be deleted or extended").

**How to apply:** never put character migration or old-field preservation into a plan or brief; plan fields/dungeons as fresh builds. Re-check this once the game has real players.
