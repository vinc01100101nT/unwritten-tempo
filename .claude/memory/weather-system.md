Built a full storm stack on branch `experiment/3d-world` (Opus, June 2026), all in `unity/Assets/Scripts/` + `unity/Assets/Shaders/`:
- `RainOverlay` + `RainScreen.shader` — screen-space rain (depth-layered, randomly-scattered drops).
- `WetGround` + `WetGround.shader` — depth-based wet darkening, puddles (world-XZ noise on flat ground), faked-fresnel reflection, animated rain ripples + **footstep ripples** (alternating L/R, world-XZ buffer pushed to shader, masked by the puddle mask so they only show on puddles).
- `PlanarReflection` — true mirror-camera planar reflection into puddles (3D world **and** Crowd-layer billboard sprites; sprites work because upright billboards share the mirror cam's yaw). Weather FX quads moved to **TransparentFX** layer to keep them out of the reflection.
- `RainAudio` — Forest Day/Night Storm loops crossfaded by `TimeOfDay.Night01`, scaled by rain intensity.

**Key decisions (not obvious from code):**
- Heavy effects (wet ground + planar reflection + footstep/ambient ripples) are **gated behind `WeatherFX.Quality >= High`**. Default is **High on PC/editor, Medium on WebGL** (`#if UNITY_WEBGL`) — protects the WebGL demo's min-spec; PC installer is the real launch target. See [[direction-2p5d-pivot]].
- Custom runtime shaders MUST be added to **Always-Included Shaders** or they're stripped from builds (RainScreen + WetGround GUIDs already added). This bit us once (cloud shadow).
- All weather is tuned live via the **DevSettings (P) panel** weather knobs (see [[dev-settings-panel]]); the GROUND-ripple splash *particle* approach was tried and **deleted** (rendered as Unity's default-particle "shuriken"; replaced by shader ripples in `WetGround`).
- **Top-splashes (`SplashOnTop` + `SplashTop.shader`, built 2026-06-21):** rain micro-splashes ON TOP of heads/canopies/rooftops — a DIFFERENT thing from the deleted ground particles (don't re-delete!). One **pooled** central manager (no per-splash MonoBehaviour, ~0 B/frame, capped at `maxSplashes`) spawns tiny camera-facing quads running the **procedural** `Unwritten/SplashTop` shader (crown ring + droplets, art-free so it can't regress to "shuriken"). Targets: player + `MonsterAI3D.Active` heads (auto, glued to the moving transform), + static props tagged with **`SplashTopVolume`** via **Tools ▸ unwritten ▸ Weather ▸ Add Rain Splash Tops** (sizes top/radius from renderer bounds). Gated behind `WeatherFX.Heavy` + live rain; DevSettings "Top splashes"/"Splash rate/size/life/range" knobs; shader GUID added to Always-Included; added to the rig in `SystemsSceneBuilder`.

**Rain polish (2026-06-21):** rain now has an **entrance/exit ramp** like snow — `RainOverlay.intensity` is the TARGET (per-map max, default 1) and `RainOverlay.Shown` is the eased value (MoveTowards over `rampTime`, default 4s) fed to the shader; `RainAudio` follows `Shown` so audio fades with the storm. **Wet puddles DECOUPLED from live rain** + transition is the puddle **AREA/COVERAGE growing, NOT an opacity fade** (user was explicit: drive the "Wet puddles"/`_PuddleAmount` slider, not `_Wetness`). `WetGround` is self-driven: on rain start wait `wetDelayIn` (5s) then SPREAD coverage 0→`puddleAmount` (the cap, default 0.75) over `wetRampIn` (10s); on rain stop linger `wetDelayOut` (10s) then recede over `wetRampOut` (10s) — runtime `puddleLevel`→`_PuddleAmount`, ramp speed = cap/rampTime so the time-to-cap is exact. Timers trigger off the raw rain *target* (`Raining`), not the eased amount. **Shader split (`WetGround.shader`):** added `_RainNow` (= `RainOverlay.Shown`); open-ground wetness + rain-impact rings (water+ground) now ride `_RainNow` so raindrops stop landing when rain stops, while standing-water puddles (reflection/fresnel/footsteps, gated by `_Wetness`=constant `wetness`×coverage) persist. ⚠️ `_RainNow` is a NEW shader property — shader's GUID already in Always-Included (no action), but a baked-material variant won't have it until reimport. `_Wetness` is now a CONSTANT opacity master (held at `wetness`, default 1), NOT transitioned. `PlanarReflection.ShouldRun` gates on `WetGround.Instance.Active` (visible puddles) not rain. `IsPuddleAt` uses live `puddleLevel`. New DevSettings knobs: "Rain fade in", "Wet soak delay/build time/dry delay/dry time"; "Wet puddles" slider = the coverage cap. **Pre-seed on load:** both `RainOverlay.shown` and `WetGround.puddleLevel` snap to full on their first LateUpdate (`primed` flag) if the map starts already-raining — so you spawn into an established storm with full rain + full puddles, no fade-in/spread-from-dry; only mid-session toggles ease.

**CHANNEL + SEQUENCE ARCHITECTURE (refactor 2026-06-22, Opus/High).** The weather layer was rebuilt around **standalone channels + composable timelines** — the user's call ("leave these micro events standalone… compose them into a reusable event"). DON'T re-couple renderers to each other.
- **`WeatherChannels.cs`** — the source of truth: 4 independent eased 0..1 values `WeatherChannel { Rain, Cloud, Snow, Puddle }`. One central easing point (`MoveTowards`, ~0 alloc). API `SetTarget(ch,target,ramp)` / `Snap` / `Shown(ch)` / `Target(ch)`. Lives on the Systems rig (added in `SystemsSceneBuilder` before `WeatherDirector`); `WeatherDirector` self-hosts one on its own persistent GameObject if an old scene lacks it.
- **Renderers are now DUMB FOLLOWERS** that read a channel — none follow each other anymore: `RainOverlay`←Rain, `CloudShadows`←Cloud (its `strength` = Cloud.shown), `SnowOverlay`←Snow, `SnowGround`←Snow (still its own slower `accum` on top), `WetGround`←**Puddle** (renders `Puddle.shown × puddleAmount` cap) + Rain (for `_RainNow`), `RainAudio`←Rain. Each keeps a self-ease **fallback** for when there's no channels hub (defensive; real game always has one).
- **`WeatherSequences.cs`** — composable timelines, one per Preset. Each = ordered `WeatherKey{ at, channel, target, ramp }` rows; the `WeatherChannels` sequencer fires keys as their time arrives (single index ptr, 0 GC). **This is the file to tune timings.** A channel HOLDS its last target between keys/sequences → after-rain puddle linger is just a late `Puddle→0` key. `SettledValue` = last key per channel.
- **`WeatherDirector`** picks the day's Preset (unchanged deterministic season pools) → on a CHANGE `channels.Play(seq)` (build-up over time: clouds→rain→puddles→storm), on LOAD (`firstApply`) `channels.Settle(seq)` (snap to settled, no replay). Removed: instantaneous `TargetsFor`/`Targets`, cloud-easing in Update, and the short-lived "preRainCloudLead/rainEntryRamp" build-up coroutine (superseded).
- **Auto-puddle**: the ONE optional cross-channel coupling — when no sequence authors puddles, `WeatherChannels.autoPuddle` derives Puddle from rain (soak delay→spread, linger→recede); a sequence with Puddle keys switches it OFF. So manual DevSettings rain still wets the ground if "Auto puddle" is on.
- **DevSettings**: Rain/Cloud/Snow/Puddle masters now snap the CHANNELS (not overlay fields); added "Puddle coverage", "Auto puddle (from rain)", and Puddle soak/build/dry timers (the old "Wet soak/build/dry" knobs moved here). The example the user wanted — *heavy clouds → very light rain → very light puddles → storm → more puddles* — is the **Thunderstorm** sequence; LightRain does clouds-first then rain 0→0.45 over 10s.
- NOTE: the **2026-06-21 "Rain polish" paragraph above is now superseded** for the easing/puddle-drive mechanism (easing centralized in channels; WetGround self-drive is fallback-only). Shader split (`_RainNow`/`_Wetness`), `primed` snap semantics, `IsPuddleAt`, planar-reflection gating all still apply.

**PROCEDURAL SKYBOX (`SkyboxSky` + `Unwritten/SkyboxClouds.shader`, 2026-06-23, Opus/High).** The wrap-around sky. A real Unity skybox (`RenderSettings.skybox` set at runtime) computed PER VIEW DIRECTION (edge-free sphere of directions — explained box-vs-dome-vs-sphere to the user: a skybox is sampled by direction so it shows no corners; functionally a sphere). Per-pixel: horizon→zenith gradient + sun disk/halo along `_SunDir` + clouds projected via `d.xz/d.y` (spread overhead, compress toward horizon, faded in above `_HorizonFade` so the projection pile-up dissolves into the horizon sky colour = no band). Reuses `CloudShadows.CloudTexture` (the `Scroll`/`WorldScale` getters were CloudDeck-only → DELETED) + its wind for drift. Storm darkening same model as the deck (cover→grey via Cloud+Rain channels). Day/night: `DayNightLight` now exposes **`SkyColorNow`** (the computed day/night+glow sky colour) which `SkyboxSky` reads as the horizon colour; zenith is its own day/night lerp; sun dir = `-dnl.transform.forward`, sun disk fades out at night (`_SunIntensity = Daylight01`). **Reflections:** `PlanarReflection` reflCam `clearFlags = Skybox` → puddles show the wrapped sky (mirror cam looks up). Main cam flipped to `clearFlags = Skybox` at runtime (`SkyboxSky.TeachCameraSkybox`) + in `Build25DSpike.BuildCamera`. **PERF guard:** skybox material changes every frame → set `RenderSettings.defaultReflectionMode = Custom` so Unity never re-bakes the env reflection cubemap (ambientMode already Flat via DayNightLight; sprites are unlit, don't sample env). Bootstrapped in `DayNightLight.Awake` + `SystemsSceneBuilder` (on Sun) + `WeatherDirector.Ensure`. Shader GUID `a1b2c3d4…` in Always-Included. DevSettings: "Cloud size (sky)/density/edge soft/horizon fade/storm darken/grey onset", "Sky gradient pow", "Sun disk size/halo spread". Re-run **Setup Systems Scene** to bake onto the Sun (else runtime Ensure spawns a standalone). Rotational realism (turn → clouds sweep, world-pinned not screen-pinned); NO positional/walk parallax (far sky, realistic) — if near parallax clouds are ever wanted, that's a separate overhead layer. **Cloud look upgrade (2026-06-23):** the bare gnomonic `d.xz/d.y` projection made horizontal STRIPES (y-floor `1e-3`→1000× stretch near horizon) + a flat single-layer look; fixed by raising y-floor to `0.06` (~17× cap, hidden by horizon fade), adding a **domain warp** (2 low-freq samples → ±0.14 UV displacement, breaks tiling) and **two altitude layers** (high cirrus via `d.y*1.45` thin/bright + low cumulus via `d.y*0.62` puffy/darker-underside, low layer rotated ~27° so seams don't align), soft-additive combined. **MOON (2026-06-23):** added a 2nd disk+halo opposite the sun (`_MoonDir = -_SunDir` → rides up as sun sets), cool white-blue, `_MoonIntensity = 1-Daylight01` (fades in at night). Leans into the happy accident the user spotted — white clouds already read as moonlit gaps at night, so a literal moon "lighting the gaps" cements it. DevSettings "Moon disk size/halo spread". ⚠️ Shader GUID got reassigned by Unity to `d17e5c6ef3d08b2448795eef8793b1e3` (placeholder `a1b2c3d4…` was never real) — synced into Always-Included in GraphicsSettings.asset.

**[HISTORICAL] VISIBLE CLOUDS via reflection (`CloudDeck`, 2026-06-23, Opus/Medium) — DELETED, see above.** User wanted to actually SEE clouds, specifically *in the wet-ground reflection*. Key realization from `PlanarReflection`: the reflection cam clears to a flat `backgroundColor` (no skybox) and its cull mask **excludes TransparentFX** — so the camera-locked FX quads (incl. a "sky backdrop") can NEVER reflect; only REAL geometry above the water plane does. So clouds must be actual geometry. Built **`CloudDeck.cs` + `Unwritten/CloudDeck.shader`**: a big translucent plane parked high (`height` 30) over the camera XZ, on a NEW **`Sky` user layer (index 10, was empty — no index shift)**. The MAIN camera is taught to SKIP the Sky layer (so it's not an unseen overhead "ceiling" on our steep top-down view), but the reflection cam renders it → **puddles become a window onto the sky**. It **samples the SAME `CloudShadows` texture + scroll + world-scale** (new public getters `CloudTexture`/`Scroll`/`WorldScale`) so the cloud you see IS the cloud casting the shadow; cover = the **Cloud channel** (thickens with the shadows). **Storm darkening (user ask 2026-06-23):** the deck greys out as the storm builds — `storminess = max(smoothstep(fairCloud, 1, cloudCover), rainShown) × stormDarken`, lerping cloud colour `cloudColor`(white)→`stormColor`(grey). Leads with cloud COVER so it darkens BEFORE the first drop (Thunderstorm seq thickens clouds first), pinned to max once raining; fair-weather puffs below `fairCloud` cover stay white. DevSettings: "Clouds in main view", "Cloud size/density/rim fade/deck height", "Cloud storm darken", "Cloud grey onset". **LOOK FIX (2026-06-23, user "doesn't look like a cloud"):** reusing the shadow's tiny `patchSize`(10) tiled the texture ~40× across the deck → a repeating speckle. Now the deck samples at its OWN `cloudSize`(default 220) so the sky gets a few BIG soft puffs; the shadow UV-scroll is converted to a world offset and re-applied at deck scale so clouds still drift in the same world dir/speed as their shadows (alignment is approximate, not exact). Added a **rim fade** (`edgeFade`, mesh UVs 0..1 → `_EdgeFade`) for the literal plane edge, AND an **atmospheric horizon blend** (`fadeStart`/`fadeEnd` world units from `_WorldSpaceCameraPos.xz`): a flat plane at a grazing camera makes a hard horizon line, and naively fading clouds to TRANSPARENT toward the horizon (the first attempt) just left a clear-blue band + a visible cloud "limit" (user rejected). The fix: by distance, blend cloud COLOUR → the EXACT sky colour (`_HorizonColor` = `CameraRig.Cam.backgroundColor`, which DayNightLight drives) AND raise coverage to FULL (`a = lerp(cloud*rim, 1, haze)`). So overhead = structured grey cloud w/ blue gaps; toward the horizon it thickens and melts into the real sky colour → the whole sky fills in and the plane edge is invisible (matches the sky behind it). No band, no boundary. DevSettings "Cloud haze start/end". Deck enlarged (size 900, height 45), softer (density 1.4, softEdge 0.6). ⚠️ If the **Sky layer was invalid when first played** (e.g. the TagManager parse error), `NameToLayer("Sky")` returns -1 → deck falls back to layer 0 (Default) and renders as a grey CEILING in the main view; fixed once the layer exists + replay. Shader GUID `c3d9f1a4…` added to Always-Included; ensured in `SystemsSceneBuilder` (on Sun) + `WeatherDirector.Ensure`. ⚠️ Reflection (hence visible clouds) is **High-tier only** (PlanarReflection gated on Heavy + puddles). Re-run **Setup Systems Scene** to bake it onto the Sun (else runtime `Ensure` spawns a standalone one).
