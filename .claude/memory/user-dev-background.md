The user is experienced in **JavaScript/TypeScript** but **new to C#** (and Unity is their first game engine).

When explaining C#/Unity code, teach by **analogy to JS/TS** concepts they already know: `using`↔`import`, attributes `[X]`↔decorators, LINQ (`.Select`/`.Where`)↔array `.map`/`.filter`, `$"..."`↔template literals, `as`↔(runtime-checked) type assertion, generics similar but runtime-affecting. Call out where C# genuinely differs (static typing, `out` params, value vs reference types, float `f` suffix, LINQ laziness).
